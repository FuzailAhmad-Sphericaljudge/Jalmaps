# JalMaps Phases

## Completed Phases
- **Phase 1 to 10**: Core application features, map, forms, basic UI and components setup.
- **Phase 11 (Charts and History)**: A fast, accessible, localised history view for each well with LTTB downsampling, charts, and compare mode.
- **Phase 12 (Realtime Updates)**: Realtime well reading updates on the UI using Supabase realtime subscriptions without manual refreshing.
- **Phase 13 (Alerts Engine)**: Created an alerts engine with background rules evaluating sensor levels, rates of drop, and generating accessible alerts for users (database models, rule lists, alerts page UI).
